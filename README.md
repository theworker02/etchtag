# etchtag

Etch timestamps and tag durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/etchtag/

## Install / run

```bash
git clone https://github.com/theworker02/etchtag.git
cd etchtag
node src/cli.js
node --test
```
